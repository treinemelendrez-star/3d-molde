# 安居家轻量化 3D 建模模块

本目录是安居家项目中“轻量化建筑体检空间证据工作台”的独立代码分区。

## 模块目标

- 建立房屋、楼层、房间、构件、病害位置的轻量化三维表达。
- 支持人工输入尺寸、坐标、构件类型和病害相对位置。
- 使用局部空间直角坐标系保证录入坐标可追溯。
- 通过 3D 视图辅助查看建筑内部构件和病害位置。
- 保持居民体检初筛口径，不输出正式房屋安全鉴定结论。

## 轻量化边界

本模块优先采用参数化构件和简单几何体表达经典建筑构件，包括墙、梁、柱、楼板、屋面、楼梯、阳台、墙脚、门窗角等。

当前阶段不纳入：

- BIM
- Revit / CAD 自动解析
- 点云
- 摄影测量
- 真实三维重建
- 复杂构件内部结构建模

## 后续开发方向

- 坐标系统：房屋坐标、房间坐标、构件表面相对坐标。
- 构件库：经典建筑构件的参数化建模。
- 视图层：旋转、平移、缩放、剖切、透明显示和构件聚焦。
- 病害层：点位、贴片或图标标记，绑定到构件数据而不是渲染对象。
- 校验层：房屋、房间、构件和病害坐标输入校验。
